
# 🏰 Kingdom Defense

## 🎮 Sobre o jogo

Kingdom Defense é um jogo 2D do gênero Tower Defense,
desenvolvido na Unity como projeto acadêmico.

O objetivo é proteger um castelo medieval contra ondas
de inimigos, construindo torres de defesa em pontos
estratégicos do cenário.

O jogador precisa administrar suas moedas, escolher
as torres adequadas e impedir que os inimigos destruam
o castelo antes de completar todas as ondas.

## ⚔️ Funcionalidades

- Menu principal com opções Jogar, Como jogar e Sair.
- Cenário medieval com caminho para os inimigos.
- Três tipos de torres: Arqueiro, Canhão e Míssil.
- Construção de torres em bases de pedra.
- Sistema de moedas para comprar torres.
- Recompensas em moedas ao derrotar inimigos.
- Ondas de inimigos com dificuldade progressiva.
- Sistema de vida do castelo.
- Temporizador da partida.
- Condições de vitória e derrota.
- Efeitos sonoros e visuais.
- Tela de instruções dentro do jogo.

## 🏹 Tipos de torre

| Torre | Características |
|---|---|
| Arqueiro | Ataques rápidos e custo menor |
| Canhão | Disparos mais fortes |
| Míssil | Maior poder de ataque e alcance |

## 🖱️ Como jogar

1. Abra o jogo e clique em **Jogar**.
2. Observe o caminho percorrido pelos inimigos.
3. Clique em uma base de pedra disponível.
4. Escolha a torre que deseja construir.
5. Utilize suas moedas para fortalecer a defesa.
6. Derrote os inimigos e receba novas moedas.
7. Resista a todas as ondas para vencer.

**Atenção:** se a vida do castelo chegar a zero
ou o tempo da partida acabar, o jogador perde.

## 🚀 Como executar

### Executável para Windows

1. Baixe a versão do jogo disponibilizada pela equipe.
2. Extraia o arquivo ZIP, caso esteja compactado.
3. Mantenha todos os arquivos e pastas do executável juntos.
4. Execute o arquivo `KingdomDefense.exe`.

Não é necessário instalar o Unity para jogar.

### Executar pelo Unity

1. Clone ou baixe este repositório.
2. Abra o projeto pelo Unity Hub.
3. Utilize uma versão compatível do Unity.
4. Abra a cena `Assets/Scenes/Menu.unity`.
5. Pressione Play para iniciar.
