# 🏰 Kingdom Defense

## 🎮 Sobre o jogo

Kingdom Defense é um jogo 2D do gênero Tower Defense, desenvolvido na Unity como projeto acadêmico.

O objetivo é proteger um castelo medieval contra ondas de inimigos, construindo torres de defesa em pontos estratégicos do cenário.

O jogador precisa administrar suas moedas, escolher as torres adequadas e impedir que os inimigos destruam o castelo antes de completar todas as ondas.

## ⚔️ Funcionalidades

Menu principal com opções Jogar, Como jogar e Sair.  
Cenário medieval com caminho para os inimigos.  
Três tipos de torres: Arqueiro, Canhão e Míssil.  
Construção de torres em bases de pedra.  
Sistema de moedas para comprar torres.  
Recompensas em moedas ao derrotar inimigos.  
Ondas de inimigos com dificuldade progressiva.  
Sistema de vida do castelo.  
Temporizador da partida.  
Condições de vitória e derrota.  
Efeitos sonoros e visuais.  
Tela de instruções dentro do jogo.

## 🏹 Tipos de torre

| Torre | Características |
|---|---|
| Arqueiro | Ataques rápidos e custo menor |
| Canhão | Disparos mais fortes |
| Míssil | Maior poder de ataque e alcance |

## 🖱️ Como jogar

Abra o jogo e clique em **Jogar**.  
Observe o caminho percorrido pelos inimigos.  
Clique em uma base de pedra disponível.  
Escolha a torre que deseja construir.  
Utilize suas moedas para fortalecer a defesa.  
Derrote os inimigos e receba novas moedas.  
Resista a todas as ondas para vencer.

**Atenção:** se a vida do castelo chegar a zero ou o tempo da partida acabar, o jogador perde.

## 🚀 Como executar

### Executável para Windows

📥 [Baixar Kingdom Defense - Versão Final](https://github.com/fernanda-code/gameTowerDefense/releases/download/v1.0.0/KingdomDefense_Executavel.zip)

Baixe o arquivo ZIP pelo link acima.  
Extraia todos os arquivos para uma pasta.  
Mantenha todos os arquivos e pastas do executável juntos.  
Execute o arquivo `KingdomDefense.exe`.

Não é necessário instalar o Unity para jogar.

### Executar pelo Unity

Clone ou baixe este repositório.  
Abra o projeto pelo Unity Hub.  
Utilize o Unity 6.3 LTS.  
Abra a cena `Assets/Scenes/Menu.unity`.  
Pressione Play para iniciar.
